# keel v0.1.0

This is the first public pre-alpha npm carrier candidate for keel. It is prepared for maintainer
byte inspection and separate 2FA approval; the workflow does not make the package public by itself.

The release contains the `keel-harness` npm tarball, its SHA-256 manifest, SPDX and CycloneDX SBOMs,
the graph-derived bundled-component inventory, and source/artifact identity metadata. Standalone
Bun binaries are intentionally excluded under ADR-0040.

Known limitation: P1-007 remains open because the strict packaged streaming-RSS target has not
passed. This pre-alpha release makes no packaged-performance claim.
