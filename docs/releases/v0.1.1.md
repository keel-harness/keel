# keel v0.1.1

This is the first intended public pre-alpha npm carrier for keel. The earlier `0.1.0` candidate was
staged but never approved or made public. This candidate is prepared for maintainer byte inspection
and is not published until separate 2FA approval.

The release contains the `keel-harness` npm tarball, its SHA-256 manifest, SPDX and CycloneDX SBOMs,
the graph-derived bundled-component inventory, and source/artifact identity metadata. Standalone
Bun binaries are intentionally excluded under ADR-0040.

This candidate includes Warden-owned connect-time destination resolution, resolved-address
classification, fail-closed whole-set rejection, and vetted-address pinning for the vendored SRT TCP
carrier. Narrow owner-managed private-address exceptions are supported. This does not cover provider
API calls, UDP/QUIC, or alternate sandbox backends.

Known limitation: P1-007 remains failed because the strict packaged streaming-RSS target has not
passed. The owner's earlier acceptance applied only to `0.1.0`; `0.1.1` cannot be tagged or staged
until the owner separately accepts that residual risk or the gate is remediated. The threshold is
unchanged, and this release makes no packaged-performance claim.
