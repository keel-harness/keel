# Support

keel is a pre-alpha, single-maintainer open-source project. Support is
best-effort; there are no response-time guarantees yet.

## Where to go

- **Bug reports and feature requests**: open a
  [GitHub issue](https://github.com/keel-harness/keel/issues) using the
  matching template. Include `keel --version`, your OS, and the exact command
  or session steps where possible.
- **Security vulnerabilities**: do NOT open a public issue. Follow
  [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
- **Questions and usage help**: open an issue with the question template.
  Please check the [documentation](docs/README.md) and
  [getting started guide](docs/guide/getting-started.md) first.

## What to expect

Issues are triaged as maintainer time allows. Well-reproduced bug reports with
version, platform, and steps are handled first. Claims about security behavior
are taken especially seriously; see the
[claim ledger](docs/quality/claim-ledger.md) for what keel does and does not
currently guarantee.
